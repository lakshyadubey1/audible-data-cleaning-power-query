# Audible Data Cleaning using Power Query

This project focuses on cleaning and standardizing an Audible audiobooks dataset using Power Query in Excel.

## Objective
To transform raw, messy data into a clean and analysis-ready dataset by:
- Standardizing text fields
- Splitting combined columns (authors, narrators)
- Converting text values to numeric formats (ratings, duration)
- Handling missing and invalid values
- Creating derived columns for better analysis

## Tools Used
- Microsoft Excel
- Power Query

## Key Transformations
- Title casing of book names  
- Splitting multiple authors and narrators  
- Converting text-based time to Duration  
- Cleaning star ratings and rating counts  
- Standardizing date and currency formats  

## Output
- Cleaned dataset ready for analysis
- Presentation documenting the transformation steps
